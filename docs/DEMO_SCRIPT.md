# One-minute demo script

1. Open VERA and read the published Night Lab rule (0:00–0:08).
2. Point out the sealed privacy boundary: DOB, student identifier, and nonce stay local; the verifier gets only pass/fail (0:08–0:20).
3. Click Review to show the public-policy assistant and its warning that it cannot inspect a credential (0:20–0:30).
4. Select Preview or Preprod and connect 1AM. Explain that changing network resets the session (0:30–0:42).
5. Generate the proof. The wallet creates the ZK proof and VERA waits for a real finalization rather than inventing a receipt (0:42–0:55).
6. Show the finalized receipt and public aggregate; repeat that no private student record was stored (0:55–1:00).

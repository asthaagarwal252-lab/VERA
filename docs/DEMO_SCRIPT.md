# One-minute demo script

1. Open VERA and read the published Night Lab rule (0:00–0:08).
2. Point out the sealed privacy boundary: birth year, enrollment status, holder secret, and nonce stay local; the verifier gets only success and a replay marker (0:08–0:20).
3. Click Review to show the public-policy assistant and its warning that it cannot inspect a credential (0:20–0:30).
4. Select Preview or Preprod and connect 1AM. Explain that changing network resets the session (0:28–0:37).
5. Press **Set up**, approve the one-time deployment, and point to the generated contract address (0:37–0:48).
6. Choose eligibility or enrollment, request the proof, approve it in 1AM, and show the finalized on-chain receipt (0:48–1:00).

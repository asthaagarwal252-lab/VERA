# Architecture

React owns session UI state and an encrypted-wallet-independent credential kept in browser local storage. The wallet connector discovers DApp Connector API v4 providers from the standard `window.midnight` namespace and prefers 1AM. Compiled Compact bindings hold public policy, nullifier, and aggregate state while reading the credential through a private-state witness. Midnight.js obtains indexer and proving configuration from the connected wallet, deploys or rejoins the contract, balances the transaction, and submits it for finalization. FastAPI serves public-policy composition, receipt validation, and aggregates using async SQLAlchemy. Neon is deployed branch-first: development is for integration and production is for finalized public records.
